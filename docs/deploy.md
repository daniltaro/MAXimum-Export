# Разворачивание бота на сервере

Бот сам опрашивает серверы MAX (long polling), поэтому **домен, HTTPS и белый IP не нужны** —
достаточно любой машины с интернетом и Docker. Служебный HTTP API слушает только саму машину.

## Что нужно от сервера

| Параметр | Минимум | Почему |
|---|---|---|
| ОС | Ubuntu 22.04 или 24.04 | на них скрипт ставит Docker сам |
| Процессор, память | 1 ядро, 1 ГБ | запущенный контейнер занимает около 12 МБ памяти |
| Диск | 10 ГБ | образ с Go-программой — около 26 МБ |
| Сеть | обычный доступ в интернет | входящие подключения не нужны |
| Цена | 200–400 ₽/мес | Timeweb, Selectel, REG.ru, любой другой хостинг |

Заказывая сервер, выберите вход по SSH-ключу — это надёжнее пароля.

## Разворачивание одной командой

С вашего компьютера, из папки проекта:

```bash
./scripts/deploy.sh root@адрес-сервера
```

Скрипт проверит тесты, скопирует текущую версию из git, отдельно передаст `.env` с токеном,
поставит Docker, соберёт образ и запустит бота. В конце покажет, что бот подключился к MAX.

Токен передаётся по шифрованному каналу SSH и в репозиторий не попадает: файл `.env`
исключён из git и из Docker-образа.

## Проверка после разворачивания

1. В журнале должна быть строка «MAX: бот @… запущен, жду сообщений».
2. Откройте бота: **https://max.ru/t747_hakaton_max_bot** и отправьте `/start`.
3. Пройдите сценарий: «Начать расчёт» → 🇨🇳 Китай → «сахар-песок» → код `1701 12 100 0` →
   5000 → 250000 → «✅ Рассчитать». Должен прийти отчёт и файл `.txt`.

## Обслуживание

| Задача | Команда (на сервере, из папки `/opt/maxexport`) |
|---|---|
| Журнал бота | `docker compose logs -f` |
| Состояние | `docker compose ps` |
| Перезапуск | `docker compose restart` |
| Остановка | `docker compose down` |
| Запуск снова | `docker compose up -d` |
| Обновление версии | повторить `./scripts/deploy.sh` со своего компьютера |

После перезагрузки сервера бот поднимается сам: у контейнера задано `restart: unless-stopped`.

## Если что-то не работает

| Что видно | Причина и что делать |
|---|---|
| `certificate signed by unknown authority` | Образ собран без сертификата Минцифры. Пересоберите: `docker compose up -d --build` (сертификат ставится внутрь контейнера при сборке) |
| `MAX не принял токен` | Неверный `BOT_TOKEN` в `.env`. Возьмите токен у @MasterBot и повторите разворачивание |
| Бот не отвечает, в журнале тихо | По одному токену может работать только одна копия бота. Остановите бота на других машинах, в том числе локальный `docker compose down` |
| `Cannot connect to the Docker daemon` | Docker не запущен: `systemctl start docker` |

## Безопасность

- Токен хранится только в `.env` на сервере, права `600`, в git и образ не попадает.
- Программа работает в контейнере от обычного пользователя, не от root.
- Порт 8080 (служебный API) доступен только с самой машины: `127.0.0.1:8080`.
- Персональные данные бот не принимает и не хранит; расчёты живут в памяти 24 часа
  и теряются при перезапуске (ТЗ §19).
- Журналы ограничены 30 МБ (3 файла по 10 МБ) и не содержат текстов пользователей.
