# ТН ВЭД ЕАЭС: проверенные коды для учебного справочника (на 21.09.2026)

The codes were checked against the current ТН ВЭД ЕАЭС / ЕТТ, which is Решение Совета ЕЭК № 80 от 14.09.2021 in its edition of 01.07.2026 ([consultant](https://www.consultant.ru/document/cons_doc_LAW_397176/)). The lookups used Альта-Софт (alta.ru) and IFCG (ifcg.ru). When a code does not exist, alta returns HTTP 404, and I used that to rule codes out.

**Short source links used in the table:**
- **A:NNNNNNNNNN** means `https://www.alta.ru/tnved/code/NNNNNNNNNN/`
- **I:XXXX** means `https://www.ifcg.ru/kb/tnved/XXXX/`

**Before you put this in the bot, four things matter:**
1. **The 10th digit is often not "0".** Many food codes are split by import season, by NY-exchange sugar price, by tariff quota (дополнительное примечание ЕАЭС к группе 02), by package size or by fortification. Store the full 10-digit code together with the text of its split.
2. **These splits mostly affect import duty.** An export declaration still needs a valid 10-digit code. For quota-split codes the usual choice is the "…9 прочие" code [med].
3. **Codes that looked plausible but do not exist** (alta 404): 1101 00 150 0, 1701 91 000 0, 1008 10 000 0, 0203 29 550 0, 1704 90 990 0 (this last one was valid before 2022).
4. **VAT in the RF is now 22%** (reduced rate 10% for food). alta shows this on every code, e.g. A:0409000000 [high].

## 4. Borderline classification cases

1. **Ароматизированный (ванильный) сахар: 1701 91 или 2106 90 / 1806 10.**
   - The explanatory notes to 1701 say sugar stays in 1701 only in solid form, even with flavouring or colouring added. Such sugar goes to 1701 91 even when sucrose is below 99.5% [high] ([alta P1701](https://www.alta.ru/poyasnenia/P1701/)).
   - Flavoured sugar syrups, and solid products that have lost the character of sugar (e.g. drink bases), go to 2106. Sugar with cocoa goes to 1806.
   - Deciding criterion: solid sugar with only flavouring or colouring and no other ingredients goes to 1701 91.

2. **Мёд с орехами: 0409 или 2008 19 / 2106 90.**
   - Heading 0409 covers only honey «при условии отсутствия в нем добавок в виде сахара или любых других веществ» [high] ([alta P0409](https://www.alta.ru/poyasnenia/P0409/)). So honey with nuts can never be 0409.
   - If the nuts give the product its character (nuts preserved in honey), it goes to 2008 19: 2008 19 990 0 for jars up to 1 kg, 2008 19 950 0 if the nuts are roasted, 2008 19 920 x for tropical nuts [med].
   - Honey with spices or other additives, where honey still dominates, is more likely 2106 90 980 x [low–med].
   - Deciding criterion: whether the nuts (the preserved plant part) or the honey gives the essential character.

3. **Халва подсолнечная: 1704 90 980 0 или 1806 90 / 2008 19.**
   - The FTS ruling puts all halva (tahini, peanut, sunflower and others) in 1704 90 980 0 [high]. Before 2022 the code was 1704 90 990 0.
   - Halva glazed with chocolate or containing cocoa goes to 1806 90 [med].
   - Deciding criterion: whether the product contains cocoa.
